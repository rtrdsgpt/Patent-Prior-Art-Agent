# CPU-only torch build (sentence-transformers' real dependency) -- without this, `pip
# install` on Linux (i.e. inside Docker) resolves the default CUDA-enabled torch wheel,
# pulling in several GB of nvidia_* packages this project never uses (no GPU in these
# containers). Confirmed how much this actually costs while building Dockerfile.airflow:
# single nvidia_cublas/nvidia_cudnn wheels alone were 400-500MB+ each. Doesn't affect local
# macOS dev (CPU/MPS wheels are already what resolves there), only Linux container builds.
--extra-index-url https://download.pytorch.org/whl/cpu
